# Veyl — релизы

Репозиторий-раздатчик: сюда сборка из
[`scxr1et/vpn-service`](https://github.com/scxr1et/vpn-service) кладёт
установщики, апдейтерные архивы с подписями и манифест обновления. Кода тут
нет и не будет — только артефакты.

## Что где лежит

```
<версия>/manifest.json   # манифест выпуска, ссылки внутри ведут на <версия>/<файл>
<версия>/...             # установщики и апдейтерные архивы с .sig
latest/manifest.json     # копия манифеста последнего выпуска
```

Адрес, зашитый в приложение, — стабильный:

```
https://raw.githubusercontent.com/scxr1et/veyl-releases/main/latest/manifest.json
```

Версионный адрес в бандл не вписывается: он меняется с каждым выпуском, а
бандл подписывается офлайн-ключом. Версионная копия нужна, чтобы видеть, что
именно выпускали, и чтобы откатить `latest` на неё.

## Как сюда попадают файлы

Пушем от workflow `release.yml` в основном репозитории — руками ничего
класть не надо. Подробности в `tools/release/README.md` там же.
